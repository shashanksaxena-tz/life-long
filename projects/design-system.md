## Description
Shared component library and design tokens used across all products.

## Components
- **Primitives**: Button, Input, Select, Checkbox, Radio
- **Layout**: Stack, Grid, Container, Divider
- **Data Display**: Table, Card, Badge, Avatar, Tooltip
- **Feedback**: Toast, Modal, Alert, Progress

## Design Tokens
- Color scales (12 steps per hue)
- Typography scale (Inter, JetBrains Mono)
- Spacing scale (4px base unit)
- Shadow and radius tokens
