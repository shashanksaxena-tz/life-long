## Description
Cross-platform mobile companion app for the productivity system. Available on iOS and Android.

## Features
- Quick task capture with voice input
- Offline-first with background sync
- Push notifications for due dates and reminders
- Widget support for home screen

## Technical Notes
- Built with React Native + Expo
- SQLite for local storage
- Background fetch for sync every 15 minutes
