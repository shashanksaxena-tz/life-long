## Objective
Define the schema for analytics event ingestion and storage in ClickHouse.

## Requirements
- Support arbitrary event properties (semi-structured)
- Efficient time-series queries
- Partition by date for fast range scans
- Support for user identification and session tracking

## Proposed Schema
```sql
CREATE TABLE events (
  event_id UUID,
  event_name String,
  user_id String,
  session_id String,
  timestamp DateTime64(3),
  properties Map(String, String),
  created_at DateTime DEFAULT now()
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (event_name, user_id, timestamp)
```
