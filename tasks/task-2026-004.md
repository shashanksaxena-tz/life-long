## Implementation
Added sliding window rate limiting using Redis.

- **Limit**: 5 login attempts per IP per minute
- **Lockout**: 15 minute cooldown after limit exceeded
- **Headers**: Returns `X-RateLimit-*` headers

## Results
- Blocked 340 brute-force attempts in first week
- Zero false positives reported
