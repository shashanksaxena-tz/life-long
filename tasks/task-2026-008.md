## Strategy
Using CRDT-based sync with SQLite as local store.

## Architecture
1. All writes go to local SQLite first
2. Background sync service pushes changes every 15 min
3. Conflict resolution: last-write-wins with vector clocks
4. Full resync on first launch after 7+ days offline
