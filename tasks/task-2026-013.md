## Implementation
Added circuit breaker using **opossum** library.

### States
- **Closed**: Normal operation, requests flow through
- **Open**: Failures exceeded threshold, requests short-circuited (503)
- **Half-Open**: After timeout, allows limited requests to test recovery

### Configuration
- Failure threshold: 50% in 10-second window
- Recovery timeout: 30 seconds
- Minimum requests: 10 before evaluation
